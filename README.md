# HORIZON RUSH · 极速地平线

**HORIZON RUSH** is a **zero-dependency pseudo-3D open-road racing game** — open `index.html` in a browser and play.  
No install, no build, no network: every car, track, scene and sound is procedurally generated.  
Every car can be driven by its own **AI racer** — watch a whole AI race, or take over at any time.

> 一款零依赖、打开即玩的 **伪 3D 开放公路竞速游戏**，对标《极限竞速：地平线》的公路竞速与嘉年华氛围。  
> 支持 **玩家手动驾驶**，也支持 **给每一辆车接入 AI 车手，让 AI 自己比赛**（全 AI 观战 / 随时接管）。

## 快速开始

**方式一（最简单）**：双击 `index.html`，或用 `启动游戏.bat` 一键打开（Chrome / Edge 110+）。

**方式二（本地服务器，推荐）**：如果双击打开时遇到浏览器限制，可在本目录执行以下任一命令，然后打开提示的地址：

```bash
# Python 3（脚本已附带）
python server.py

# 或直接用 Python 内置服务器
python -m http.server 8080
# 浏览器打开 http://127.0.0.1:8080/
```

> 无需安装任何依赖，无需构建、无需联网。所有画面（赛道、车辆、场景、天空）与声音（引擎、音乐、音效）均为**程序化生成**，没有一张图片、没有一个音频文件。

## 游戏模式

| 模式 | 说明 |
| --- | --- |
| **快速比赛** | 从 4 站赛道中任选一站，选车、选难度，与 7 位 AI 车手比 2 圈 |
| **冠军赛** | 四站积分赛，25-18-15-12-10-8-6-4 积分制，总分最高者加冕「地平线冠军」 |
| **AI 观战** | **全部 8 辆车由 AI 驾驶**，导演机位自动切车；可 Tab 切车、Enter 随时接管、T 加速观战 |
| **自由驾驶** | 没有比赛、没有终点，沿着环岛公路自由驾驶，AI 车辆同场巡游 |

### AI 相关玩法（核心特色）

- **每一辆车都接入了独立的 AI 车手**：8 辆车各有不同的 AI 性格（精准 / 凶狠 / 稳健 / 激进 / 老练），走线、刹车点、超车侵略性、失误率均不同。
- **AI 自己打比赛**：进入「AI 观战」，8 辆 AI 赛车完整跑完比赛，有排名、圈速、结算。
- **随时接管**：观战中按 `Enter` 接管当前镜头车辆，立刻从观众变成车手；按 `H` 把车交还 AI。
- **自动驾驶**：任何时候按 `H` 让 AI 替你驾驶你的赛车（也可在选车界面开启「自动驾驶」）。
- **观战倍速**：`T` 在 1x / 2x / 4x 之间切换，快速看完一整场 AI 大战。

## 内置自检（重要）

本项目在无法使用自动化测试的环境中开发。为便于验证逻辑正确性，内置了一个自检页面：

**浏览器打开 `index.html?selftest=1`**

它会用游戏真实代码路径检查：

1. 模块与配置完整性（8 车 × AI 性格、4 站赛事）
2. 赛道生成：字段、闭合性、曲率/宽度/走线约束、发车格、确定性
3. 物理：0-100km/h、极速、氮气、越野、碰撞分离、复位、非法输入兜底
4. **8 辆 AI 完整跑完 3 圈**（纯逻辑模拟 120Hz）：全部完赛、圈速合理、同种子确定性、AI 风格差异、自动驾驶也能完赛
5. 比赛流程与结算数据（名次表 / 奖金 / 按钮）

页面会显示 PASS/FAIL 列表。若全部通过，刷新页面即可正常游玩。若出现 FAIL，请把页面内容与 F12 控制台截图反馈。

## 技术架构

纯静态、零构建、**经典 `<script>` 加载**（不是 ES Module，因此 `file://` 双击也能跑）。

```
horizon-rush/
├── index.html            # 页面骨架：canvas + #ui-root + 脚本加载顺序
├── ARCHITECTURE.md       # 模块接口契约（开发用）
├── README.md
├── css/style.css         # 全部界面样式（Forza Horizon 风格）
└── js/
    ├── config.js         # 车辆/赛事/难度/设置/操作说明等数据
    ├── util.js           # 数学、随机数（确定性）、时间格式化、存储、DOM 工具
    ├── audio.js          # WebAudio 程序化引擎/环境音/音乐/音效
    ├── track.js          # 赛道生成：星形闭合回路 + Catmull-Rom、走线、发车格、场景物
    ├── car.js            # 车辆物理（赛道空间一维+横向模型）
    ├── ai.js             # AI 车手：循迹、速度规划、超车、避让、个性与失误
    ├── render.js         # Canvas 2D 伪 3D 渲染：投影、路面、场景、车辆精灵、特效
    ├── ui.js             # 菜单 / HUD / 小地图 / 结算 / 暂停 / 设置
    ├── game.js           # 主控：状态机、输入、竞速管理、冠军赛、存档、主循环
    └── selftest.js       # ?selftest=1 自检
```

### 关键设计

- **赛道空间物理**：所有车辆状态用「沿赛道距离 `s` + 横向偏移 `x` + 前向速度 `v`」描述，物理与 AI 都在一维+横向上计算，再投影到 3D 世界。稳定、不会穿模、AI 容易调。
- **固定步长**：物理 120Hz 固定步长 + 渲染插值（帧率无关）；观战倍速通过增加 tick 数实现。
- **确定性**：赛道生成与 AI 决策只使用种子随机数（`mulberry32`），同种子结果一致，便于复现。
- **渲染与逻辑分离**：`render.js` 只读 `frame` 数据，不修改游戏状态；`ui.js` 只读 HUD 数据并回调 handlers。
- **防御式编程**：所有模块对空值/NaN 容错；启动时校验模块完整性；运行时错误会显示可读的错误覆盖层而不是白屏。

## 发布到公网（GitHub Pages / Netlify）

本项目是纯静态站点（相对路径、无构建），可直接托管到 GitHub Pages。

### 方案 A：一键上传 GitHub 并开启 Pages

1. 安装 [Git for Windows](https://git-scm.com/download/win)（可选安装 [GitHub CLI](https://cli.github.com/) 并执行 `gh auth login`，脚本会自动建仓库 + 开 Pages）
2. 双击本目录的 `上传到GitHub.bat`（或右键 `upload-to-github.ps1` → 使用 PowerShell 运行）
3. 按提示操作：
   - 检测到已登录的 `gh`：自动创建 **public** 仓库、推送、开启 GitHub Pages，并打印公网地址
   - 没有 `gh`：先在 https://github.com/new 创建**空的 public 仓库**（不要勾选 README），输入用户名后脚本自动推送
4. 公网地址形如 `https://<你的用户名>.github.io/horizon-rush/`（首次部署需等待 1~2 分钟）

### 方案 B：最快拿公网链接（无需 Git）

1. 打开 https://app.netlify.com/drop
2. 把整个 `horizon-rush` 文件夹拖进页面
3. 登录后即可得到形如 `https://xxxx-xxxx.netlify.app/` 的公网链接

> 提示：仓库/站点是公开的，请勿放入任何密钥或隐私文件；本项目本身不含密钥。

## 已知限制

- 本项目在**无法执行 shell / Node / 浏览器自动化**的环境中开发，全部模块经过多轮静态审查与交叉接口核对，运行时的最终表现以 `index.html?selftest=1` 自检与实机为准；如遇问题请反馈错误覆盖层或自检页内容。
- 这是**伪 3D**（经典赛车游戏投影方式）而非真 3D 引擎：弯道是横向位移的视觉效果，坡道有但无法做出真正的立体交叉/跃起。
- 没有联网对战、没有开放世界自由探索地图（赛道是闭合环线）。
- 车辆无法倒车（`S` 是刹车）；卡住时按 `R` 复位。
- 若浏览器禁用了 localStorage（部分 `file://` 环境），存档会退化为本次会话内有效。
- 音效需要用户第一次点击/按键后才会启动（浏览器自动播放策略）。

## 常见问题

**双击 index.html 后黑屏或报错？**  
先确认 `js/` 下 10 个文件都在；打开 `?selftest=1` 查看具体失败项；使用 Chrome/Edge 110+。若浏览器对本地文件限制严格，用上面的 Python 本地服务器方式打开。

**画面卡顿？**  
设置 → 画质 → 低/中，会降低绘制距离、粒子与分辨率倍率。

**AI 太快/太慢？**  
选车界面可切换难度：新手 / 职业 / 传奇。

**如何重置存档？**  
浏览器控制台执行 `localStorage.removeItem('hr_save_v1')` 后刷新。
